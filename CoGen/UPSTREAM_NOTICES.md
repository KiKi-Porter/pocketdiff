# Upstream and Data Notices

This snapshot contains code and pretrained parameters from upstream projects
alongside CoGen-specific code. The original ligand-generator license notice
is preserved as `ligand_generator/LICIENCE`; the Apo2Mol license is preserved
as `pocketdiff/Apo2Mol-main/LICENSE`. The official encoder source is included
under `pocketdiff/targetdiff-main/targetdiff-main/`.

Before publishing this combined snapshot, review each upstream software
license, pretrained-weight terms, and dataset redistribution conditions.
Prepared caches may contain structural data. They are excluded from this
public snapshot; any locally supplied cache must be redistributed only when
its structural-data permissions have been checked separately.
No blanket license for all CoGen-specific files is asserted here.
